🎯 Quick Start

  1. Choose a platform: Heroku (easiest), Railway, Render, or Docker + VPS
  2. Generate SECRET_KEY: Use python -c "import secrets; print(secrets.token_urlsafe(50))"
  3. Deploy:
    • Windows: deploy_heroku.bat your-app-name
    • Linux/Mac: bash deploy_heroku.sh your-app-name
  4. Configure: Set environment variables on platform dashboard
  5. Verify: Run python deployment_checklist.py

  • DJANGO_DEBUG = False
  • DJANGO_ALLOWED_HOSTS = yourdomain.com

  • POSTGRES_USER = clindocs_user
  • POSTGRES_PASSWORD = strong-password
  • POSTGRES_HOST = database-host
